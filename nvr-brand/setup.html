NVR — run the database setup

Both SQL files load automatically. Three steps, no file editing.

  1. Click Copy SQL. It copies supabase.sql and supabase-team.sql stitched together, in that order.
  2. In Supabase: SQL Editor → New query. Clear everything, paste (Ctrl+V), press Run. If it warns about replacing a function, that's expected.
  3. Supabase Authentication → Sign In / Providers → Email → turn OFF "Confirm email" → Save.

Running it twice is safe. Every statement is create table if not exists, create or replace, or drop policy if exists, so you can paste it again without anything breaking.

Team members need accounts first. Create them in Supabase Authentication → Users → Add user (same email they will sign in with). Then open admin.html, sign in as the owner, and use the Team tab to set each person's role: staff or co-seller. Co-sellers also need a seller row linked to them.

If it turns red, screenshot the error — Supabase names the exact statement that failed.

What each role sees

Owner — everything: sellers, listings, orders, payouts, team.
Staff — sellers (approve/decline, no payout details), listings, orders. No payouts, no team.
Co-seller — only their own pieces, their own payouts and their own seller row.
