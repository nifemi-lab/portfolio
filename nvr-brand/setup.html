NVR — run the database setup

Three steps. No file editing needed.

  1. Click Copy SQL below.
  2. In Supabase: SQL Editor → New query. Clear everything, paste (Ctrl+V), press Run.
  3. Supabase Authentication → Sign In / Providers → Email → turn OFF "Confirm email" → Save.

Running it twice is safe. Every statement is create table if not exists or drop policy if exists, so you can paste it again without anything breaking.

If it turns red, screenshot the error and it will name the exact statement.
