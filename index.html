About

I'm a developer who likes the part where a messy problem turns into a simple interface.

I started in HTML and CSS, got curious about how the data was shaped, and ended up writing SQL queries too. That loop — interface, logic, database — is where I'm most useful.

Most of my work is client-side with a real database behind it: quote flows, reservation forms, dashboards. Outside of code I'm usually reading or rebuilding the same side project for the third time.
